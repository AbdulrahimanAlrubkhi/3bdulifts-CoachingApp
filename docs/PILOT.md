# Two-week pilot checklist (3–5 clients)

## Before day 1
- [ ] Deployed with migrations `0001`–`0007`; SMTP configured; you are the coach (`DEPLOY.md` §1)
- [ ] Smoke test passed on **your own iPhone and an Android phone** (`DEPLOY.md` §1.5)
- [ ] First backup taken and stored privately (`DEPLOY.md` §3.1)
- [ ] Each client invited by email; each told: "photos and numbers are private to you and me; you choose separately in *More → Sharing my results* whether anything may be published"
- [ ] For each client: targets set, a routine assigned, meal plan if used, subscription entered

## Every day (5 minutes)
- [ ] Dashboard: anyone flagged? (missed check-in, rarely logs food, few workouts, stalled weight)
- [ ] Any client message about a problem → write down: phone model, what they tapped, time, the reference code on any error page

## Every week
- [ ] Read weekly check-ins and photos; send weekly feedback (it shows on their Today)
- [ ] Take a backup (database + photos)
- [ ] Note: which screen did clients use most / least? What did anyone ask "how do I…?" about?

## Watch for (stop and fix before continuing)
- Anyone seeing another client's name, numbers or photo (outside a challenge leaderboard)
- A workout or check-in that was saved but later missing
- Password reset or sign-up emails not arriving
- Totals that don't match what the client logged

## End of pilot (day 14)
- [ ] Ask each client 3 questions: what was easiest, what was annoying, would they pay to keep using it
- [ ] Decide which of the UX recommendations in `REVIEW.md` to build next
- [ ] Archive or keep clients; delete test accounts (`DEPLOY.md` §4)
